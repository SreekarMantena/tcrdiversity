# TCR germline diversity

This repository contains the sequences of common validated TCR alleles, processed as described in the TCR genetics manuscript. These alleles were observed in publicly-available expressed human repertoires. In the future, we are hoping to be able to make the sequences of all discovered alleles available as well. Consortia data usage restrictions currently prevent such a public release, but we are in conversations with the relevant parties to try to make this possible.

v1.0 of the allelic reference is available as a fasta file within this repository. Each header contains the allele sequence, the cumulative number of reads that exactly supported that allele sequence, and, for alleles not present in the IMGT database (6/11/25 release), an annotation indicating whether they were observed in a recent study that profiled expressed TCR repertoires (PMID: 36796364). These alleles were named based on the VDJbase/OGRDB interim convention, wherein the variants that distinguish the allele from the closest known allele are listed in the name.
